# Kendrio API Explorer — Odoo 17.0 Branch

This branch (`17.0`) follows the [Odoo Community Association (OCA)](https://github.com/OCA) repository convention:
the module lives inside a subfolder named after the module itself.

```
KendrioAPI/          ← Odoo module (add this path to your --addons-path)
├── __manifest__.py
├── __init__.py
├── controllers/
├── models/
├── security/
├── static/
└── views/
```

## Installation

Add the parent directory of `KendrioAPI/` to your Odoo `--addons-path`, then install **Kendrio API Explorer** from the Apps menu.
